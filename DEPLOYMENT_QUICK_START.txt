🚀 DEPLOYMENT STEPS (3 EASY STEPS):

1. PUSH TO GITHUB:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main

2. DEPLOY BACKEND TO RENDER:
   a) Go to render.com → New Web Service
   b) Connect your GitHub repo
   c) Name: pakistan-bakery-api
   d) Build: pip install -r api/requirements.txt && playwright install
   e) Start: uvicorn api.main:app --host 0.0.0.0 --port $PORT
   f) Deploy and copy the URL (e.g., https://pakistan-bakery-api.onrender.com)

3. DEPLOY FRONTEND TO VERCEL:
   a) Go to vercel.com → Add Project
   b) Import your GitHub repo
   c) Root Directory: dashboard
   d) Add Environment Variable:
      VITE_API_URL = https://pakistan-bakery-api.onrender.com (from step 2)
   e) Deploy
